# EFREI — Examen blanc CEH (Certified Ethical Hacker 312-50)

Application web **statique** (aucun serveur, aucune base de données) pour s'entraîner à l'examen CEH.

## Fonctionnalités
- **Accès réservé EFREI** : inscription anonyme, débloquée par une adresse `@efrei.fr` (vérification 100 % côté navigateur, aucun e-mail stocké ni transmis).
- **370 questions** réparties par thème (issues des 3 jeux de questions fournis)
- **Format CEH** : épreuve de **125 questions** par défaut (30 / 60 / 125 / toutes au choix), tirage équilibré par thème.
- **Réponse à la demande** : le bouton « Voir la réponse » révèle la bonne réponse d'une seule question ; sinon la correction n'apparaît qu'à la **finalisation** (bouton « Terminer le test » ou minuteur écoulé).
- **Scoring** : note sur N, pourcentage, **score pondéré /100 (barème CEH)**, seuil de réussite **70 %**, et **score par thème**.
- Minuteur optionnel (4 h × N/125, comme le CEH), navigation par palette, marquage de questions, correction détaillée, impression/PDF.


Usage pédagogique interne EFREI — module Ethical Hacking.
